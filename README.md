Hello, this is the Java version of the Rigel browser

To run the application, ensure that you have downloaded VS Code or have access to a terminal, afterwards, make sure you download the latest zip file from the releases called Rigel Dist


Afterwards, To run the file, ensure you have set your path to the rigel dist folder by running the command in the terminal by copying and pasting into the terminal

cd "Replace this quotation with your rigel dist folder"

Afterwards copy and paste the command to below to then run the command in the terminal


./jdk/Contents/Home/bin/java -XstartOnFirstThread -cp "./rigel-dist/classes:./rigel-dist/lib/*" RigelApp 

That's it
