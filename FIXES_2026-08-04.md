# Rigel fixes — 2026-08-04

- Capture protection now re-scans all Rigel/WebKit/AppKit windows instead of protecting the initial shell only once.
- Added newer SkyLight `SLS*` private-symbol fallbacks alongside the older `CGS*` names and reapplies both AppKit sharing exclusion and compositor exclusion after fullscreen/compositor changes.
- YouTube's fullscreen button and keyboard toggle now stay inside Rigel's protected SWT shell rather than creating a native WebKit fullscreen window.
- YouTube recommendation strips, end-screen cards, pause overlays, and related dynamic player artifacts are suppressed and rechecked during fullscreen.
- The keyboard-focus shim no longer steals focus from normal custom web-app UI; it is limited to explicit canvas/game/application surfaces, preventing ChatGPT menus and panels from collapsing immediately.

Verification performed in the available headless environment:
- All 17 Java source files compile cleanly with Java 21 and the bundled dependencies.
- The runtime-decoded fullscreen and focus-shim JavaScript pass `node --check`.
- `target/rigel.jar` was rebuilt with the patched classes while retaining the supplied macOS native library.

Limit: macOS capture exclusion is best-effort. The public `NSWindowSharingNone` behavior is not a guarantee against every modern ScreenCaptureKit capture path, and private SkyLight APIs can change between macOS releases.
